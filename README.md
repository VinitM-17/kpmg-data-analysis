# 📊 KPMG Data Analysis — Excel Project

A comprehensive data analysis project built on the KPMG dataset, 
completed as part of **Course 2: Data Management and Analysis with MS Excel**.

## 🗂️ Dataset
Four datasets were analysed:
- **Customer Address** — location and property valuation data
- **Customer Demographics** — personal, job, and wealth information
- **Transactions** — 20,000 sales records across 2017
- **New Customer List** — 1,000 potential new customers

## ✅ Tasks Completed
| Task | Description |
|------|-------------|
| Task 1 | Data Cleaning — duplicates, formatting, gender standardisation |
| Task 2 | Customer Segmentation — by wealth, gender, and industry |
| Task 3 | Transaction Analysis — monthly trends, brand & product performance |
| Task 4 | New Customer Insights — demographics, location, revenue potential |
| Task 5 | CLV Analysis — Customer Lifetime Value calculation by segment |
| Task 6 | Executive Summary — key findings and strategic recommendations |

## 🔧 Tools Used
- Microsoft Excel (PivotTables, SUMIF, AVERAGEIF, COUNTIFS, Charts)
- Python (openpyxl, pandas — for report generation)

## 📈 Key Findings
- Annual revenue: **AUD 21.74 million** (FY2017)
- Top brand: **Solex** (20.3% revenue share)
- Average CLV: **~AUD 66,700** across all segments
- NSW holds **50.6%** of new customer prospects
- Peak sales month: **October** | Lowest: **September**
